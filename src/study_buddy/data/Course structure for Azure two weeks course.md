Let’s talk a little bit about the tech stack.

What are we using in this course?

We’ll use Visual Studio Code as the IDE.

We’ll use it for some simple React development and deployment later on.

We’ll also work with the Bash CLI, so the terminal is very important.

Then we’ll work with Git Bash and version control locally, together with GitHub for storing repositories and version control online.

We’ll also use React.

This is mainly to demonstrate a web application.

You can create your own app if you want, but if you follow along with me, I’ll mostly create a simple Hello World example and use that one for deployment.

So we’ll create a very simple web app.

Then we’ll use Docker to containerize the application.

After containerizing it, we’ll move into Azure.

Inside Azure we’ll work with Azure Container Registry so that you can deploy the containerized application there.

Then later on you can deploy it into Azure Web Apps or Azure App Services.

I’ll also show you how to deploy directly from React into Azure App Services.

Now some notes about how you should study.

A few study technique tips:

First, go through the overview and glossary inside the exercises beforehand.

This gives you some priming about what you are supposed to learn.

Then go into the videos.

Watch them, pause them, code along, work along, or write down notes based on the theory.

Type out the code yourself instead of copy-pasting it.

Of course, you can watch the videos several times.

Do this before class if you are studying live with me.

Then during class, discuss with classmates.

This gives you multimodal learning and social learning.

Bring your questions to class and ask me or ask your classmates.

We also have some practical exercises.

Go back into the videos, check with LLMs, and use the resources I’ve added.

Then do the practical and theoretical exercises so that you learn more.

Note that this course is not very exercise-heavy.

However, the exercises that do exist are important to complete.

It’s also very good to spend time working on the lab since the course is quite short.
